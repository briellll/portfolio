# Perfil de Links Sociais

Uma página simples de perfil pessoal com links para redes sociais, criada com HTML e CSS.

## Tecnologias Utilizadas

- HTML5
- CSS3

## Como Usar

1. Clone este repositório.
2. Abra o arquivo `index.html` em seu navegador web.
3. Personalize os links e informações no código HTML conforme necessário.

## Estrutura do Projeto

- `index.html`: Arquivo principal da página.
- `style.css`: Estilos da página.
- `assets/images/`: Pasta com imagens (avatar, favicon, etc.).
