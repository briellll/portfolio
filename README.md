# Shell Portfolio

Portfólio em forma de terminal interativo. Um arquivo HTML, sem framework e sem
dependência além da fonte — os gráficos são desenhados em canvas na hora.

**Gabriel Morais** — Analista de Redes Jr · Santarém, PA

## Como rodar

Abra o `index.html` no navegador. Não tem build, não tem instalação.

## O que tem

- Comandos de verdade, com histórico (`↑`/`↓`), Tab que completa e `Ctrl-L`
- Visita guiada: o terminal digita o primeiro comando sozinho
- Saída digitada caractere a caractere, com aceleração progressiva — qualquer
  tecla escreve o resto na hora
- `lab`: seis níveis de linha de comando Linux no estilo OverTheWire Bandit
- Quatro temas de fósforo (`theme amber|green|ice|paper`)
- Respeita `prefers-reduced-motion`

## Comandos

| | |
|---|---|
| `whoami` `experiencia` `certs` `stack` | currículo |
| `projects` `show 1` `ls` `cat` | projetos e arquivos |
| `traceroute` `scan` `neofetch` | trajetória e áreas |
| `lab` | laboratório de Linux |
| `guia` `man` `theme` `matrix` | ajuda e enfeites |
